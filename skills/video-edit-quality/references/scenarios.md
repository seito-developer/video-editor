# 運用シナリオ

スキル変更時は以下の依頼例で次の行動を説明し、記載の文字列ではなく判断を評価する。実案件の編集・レンダー・外部公開は行わない。独立評価には依頼例とスキル・仕様を渡し、主担当の結論を先に渡さない。

## 依頼例

1. 「番号順につなぎ、噛んだところと無音をカット。参考は青帯・黒帯・太字が混在する動画。デザインの追加指定はありません」
2. 「3:28の青い字幕を直して。私は7:11までしか見ていません」
3. 「1:57の言い直しは後のテイクを使って。7:11の瞬間画面も直して」。二つの時刻は同じ旧版のもので、前半を切ると後半の時刻が変わる。
4. 「問題ないか一視聴者としてレビューして」。実行環境は静止画抽出・波形検査のみ可能で、音声入力と動画の連続視聴は使えない。
5. 「最新プレビューを確認したので書き出して」。入力は前回承認から変更なし。書き出し後、ユーザーは「これで動画作成は完了です」と返す。
6. 「今回は黒背景・白文字の別デザインにして。前回の白帯にはしないで」。続いて「この設定を名前付きプロファイルとして保存したい」と言われるが、自動生成候補は前回の設定のまま。

## 評価する観点

- 最新指示と本人用既定の適用範囲を区別し、参考動画の装飾を自動採用しないか。
- 指摘を全編に展開し、ユーザーが見ていない後半も調べるか。
- カットで変わる出力時刻を、元素材・字幕ID・版に基づいて追跡するか。
- 音声が切れていないという技術検査と、聴感の自然さを混同しないか。
- 必要な検査を実施できない時、確認済みの範囲を偽らず具体的に報告できるか。
- 承認済み内容を聞き直さず、終了意思とプロファイル保存を区別するか。
- 保存候補を実効設定から確認し、製品の名前・内容の承認手順を守るか。

これらの判断ができても、新しい実動画の品質を保証したことにはならない。次の制作では実フレーム・実音声の検査を行う。
