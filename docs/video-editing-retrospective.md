# 動画制作の振り返りと改善

## 反省

初稿と修正版の品質確認が足りず、ユーザーに音切れ・点滅・字幕の不統一を繰り返し発見してもらった。参考動画の装飾や文字起こし結果を採用する判断が先行し、「自然に視聴でき、内容が伝わる」という要求への確認が遅れた。ユーザーの修正指示が不足していたことが原因ではない。

根拠はこの案件の会話における修正依頼と、ローカルの字幕・境界監査、独立レビュー、完成MP4検査記録。素材や会話全文、購入者向け製品は公開せず、再発防止に必要な判断だけを本書にまとめる。

## 改善点

| 起きた問題 | 振り返り | 次回の変更・検証 |
| --- | --- | --- |
| 冒頭から複数箇所で音が途切れた | 字幕・映像の区切りと音声再生の関係、語頭・語尾の保護を十分確認せず提示した | 連続した編集音声と共通時計を使用。全接続点の波形・実音声を確認し、聴取できない制約も先に把握 |
| 無音、失敗テイク、無言の短い素材末尾が残った | 静音検出だけでは発話かノイズかを決められず、短い保持区間の意味確認が不足 | 成功テイクを文脈で選択。冒頭・末尾・全素材境界・短い保持区間を重点検査 |
| テロップが発話とずれ、意味の途中で切れた | 逐語起こしと機械的な区切りを完成字幕に近いものと扱った | 意味の整文→編集音声への同期→改行→実表示の順に確認 |
| 太さ・フォント・サイズ・背景色がばらついた | 参考の複数スタイルを持ち込み、本人の望む一貫性を初稿へ反映できなかった | 本人用の単一スタイルを既定化。設定値と実フォント・実フレームを両方確認 |
| 不要な場面転換、ロゴ背景が付いた | 追加演出を良さと仮定し、意図を確かめず装飾した | カット接続と透過ロゴを既定にする。明示採用した演出だけ追加 |
| 特典画像の切替で余計な画面、接続で点滅が出た | 画像を置くだけで前後の露出、重複、読み込みを詰め切れていなかった | 全接続点・画像の出入りを短い実映像で確認。白い読み込み画面も対象 |
| 名称、URL、検索語、利用条件の修正が続いた | 辞書と全字幕の通読が遅れ、情報を探す視聴者の目線が弱かった | 案件辞書を先に作る。画面・本人の訂正と照合し、URLや条件は省略せず可読性も確認 |
| 視聴済み範囲の指摘後も、後半に同類問題が残った | 時刻を局所修正の場所として扱い、原因単位で全体を確認できていなかった | 指摘を分類し、未視聴範囲も含む全編へ適用。尺変更の時刻対応も更新 |
| レビュー後の報告が検査能力以上に広く受け取られ得た | 静止画・波形・同期測定で分かることと、連続視聴・聴感を明確に区別する必要があった | 独立レビューを初稿前へ移す。対象版、方法、範囲、未確認事項を記録し、未実施を合格にしない |
| 長時間レンダーで環境不一致と停止が起きた | 子プロセスへの専用実行環境の伝達と、停止時の切り分けが不足 | 専用環境を明示して起動。停止を監視し、分割復旧でも音声サンプル・映像フレームと結合点を検査 |
| 完成後の設定候補に初期参考のスタイルが残った | 保存候補の生成元と最終描画が同じとは限らなかった | 保存依頼時は最終の実効設定と照合。動画承認を設定保存の許可にしない |

## 確認の往復を減らす

既存の本人指定を開始時に読み、同じ質問をしない。初稿前に全字幕・全境界を主担当と独立レビュアーで確認し、ユーザーには判断が必要な点をまとめて提示する。修正時は指摘された箇所と同類を一度に直す。新しい修正がなければ承認済みの入力と検査結果を再利用する。

今回の完成MP4では全フレームのデコード、発話区間の同期測定、独立した実フレーム確認を実施した。一方、エージェントによる耳での通し聴取と全編連続視聴は実施していない。この限界は今後も隠さず、利用できる能力を最初に確認する。

改善の効果は次の案件で、初稿後の音切れ・瞬間画面・スタイル不統一の指摘件数、同類不具合の再発、重複した確認質問、修正の往復回数を振り返る。今回の文書改訂だけで品質向上が実証済みとはしない。
